# Security Policy

## Supported Versions

The following versions of `ultima-sdk-python` are currently receiving security updates:

| Version | Supported          |
| ------- | ------------------ |
| latest (main) | :white_check_mark: |
| older releases | :x: |

We recommend always using the latest release from the `main` branch.

## Reporting a Vulnerability

We take security vulnerabilities seriously. If you discover a security issue in `ultima-sdk-python`, please **do not** open a public GitHub issue.

### Preferred Method: Private Vulnerability Reporting

Use GitHub's built-in **[Private Vulnerability Reporting](https://github.com/UltimaWorks/ultima-sdk-python/security/advisories/new)** feature to report vulnerabilities confidentially. This allows us to review, triage, and patch issues before public disclosure.

### What to Include

When reporting a vulnerability, please provide:

- A clear description of the vulnerability
- Steps to reproduce the issue
- The potential impact (e.g., data exposure, code execution, denial of service)
- The affected version(s)
- Any suggested mitigations or fixes (optional but appreciated)

## Response Timeline

- **Acknowledgment**: Within 48 hours of receiving your report
- **Initial Assessment**: Within 5 business days
- **Patch / Resolution**: Depends on severity; critical issues will be prioritized

## Disclosure Policy

We follow a **coordinated disclosure** model. We ask that you give us reasonable time to address the issue before any public disclosure. We will credit reporters in our release notes unless anonymity is requested.

## Scope

This policy covers the `ultima-sdk-python` library itself. Issues in third-party dependencies should be reported to their respective maintainers, though we appreciate heads-up notifications.

## Contact

For general security questions or if private reporting is unavailable, you may reach the maintainers via the [UltimaWorks GitHub organization](https://github.com/UltimaWorks).
